# Terrafolk 캐릭터 디자인 방향 선택서

2026-10-18 · 관전 몰입(주민 생명감) 기준으로 정리했습니다.
**선택해 주시면 그 방향으로 작업을 재개합니다.** (선택은 항목 번호로, 복수 조합 가능 — 예: "1-B, 2-ㄱ")

---

## 현재 상태 (기준선)

| 구분 | 네이티브 앱 (3D) | 웹 (레거시 FE) |
|---|---|---|
| 주민 | Kenney 캐릭터 GLB(남 6·여 5종, CC0) — 블록 미니피그 풍 | LPC 2D 스프라이트(픽셀아트, 의상 레이어 합성) |
| 애님 | 보행/대기(+착용 아이템 부유) | walk/idle/sit/slash/thrust 시트 |
| 착용 | 본 앵커 3D 부착(안경·모자 등 Kenney 부속) | LPC 부품 레이어 합성 |
| 동물 | Kenney 동물 GLB 5종 | 2D 스프라이트 |

개인화: LPC look JSON(uuid·sex·age)이 성별 모델 선택 + 착용 id를 구동 — 방향을 바꿔도 이 데이터 계약은 유지 가능.

## 1. 아트 스타일 방향 (택 1)

### 1-A. 현행 Kenney 블록 미니피그 유지 · 마감 개선
- 룩: 지금 화면 그대로 + 개선(그림자·외곽선·색 보정)
- 예시: https://kenney.nl/assets/category:3D (3D 자료실에서 'Mini Characters' 검색 — 현재 사용 중인 팩)
- 장점: 즉시 계속 작업 가능 · 착용 시스템 호환 · CC0 라이선스 무료 · 소품(Kenney)과 톤 일치
- 단점: 표정·관절 표현 한계 → 감정 전달이 이름표·말풍선에 의존
- 규모: 소 (마감 튜닝 수준)

### 1-B. 스타일라이즈드 로우폴리로 교체 (권장)
- 룩: 좀 더 사람다운 비율의 로우폴리(Quaternius/웨스턴 풍 커스텀 리깅) — 원시 부족 느낌 살리기
- 예시: https://quaternius.com (CC0 애니메이티드 캐릭터 팩 — 'Animated Characters' 시리즈)
- 장점: 관전 몰입↑(표정 실마리·포즈 전달) · 애님 확장성(작업·수면·운반) · 착용 본 앵커 그대로 재사용
- 단점: 모델·애님 제작 필요(에셋 구매/자작) · 소품과 톤 재정렬 필요
- 규모: 중 (주민 모델 세트 + 애님 리깅)

### 1-C. 치비(큰 머리) 스타일
- 룩: 2~3두신 만화적 비율 — 감정 표현 최강
- 예시: https://kaylousberg.itch.io (토이풍 치비 캐릭터 라이브러리 · 상업 OK 라이선스)
- 장점: 표정·감정 가독성 최고 · 귀여움으로 관전 부담↓
- 단점: 원시 생존·죽음 톤과 이질 가능 · 시리어스 연출(장례)과 균형 필요
- 규모: 중

### 1-D. 복셀(마인크래프트풍)
- 룩: 복셀 조형 — 착용·도구 표현이 블록 교체로 자연스러움
- 예시: https://kenney.itch.io ('Voxel' 시리즈 검색 — 복셀 캐릭터·소품 세트)
- 장점: 제작·변형 쉬움 · 커뮤니티 친숙
- 단점: 레퍼런스가 강해 독창성↓ · 부드러운 애님 한계
- 규모: 중

### 1-E. LPC 2D를 3D 씬에 빌보드/슬라이스로
- 룩: 웹 FE와 완전 동일(픽셀아트 주민)
- 예시: https://sanderfrenken.github.io/Universal-LPC-Spritesheet-Character-Generator (LPC 생성기 — 웹 FE가 쓰는 부품 체계)
- 장점: 웹·앱 룩 100% 일치 · 기존 의상·애님 자산 전부 재사용
- 단점: 줌 인 시 해상도 한계 · 회전/조명 표현 제약 · "3D 세계에 스티커" 느낌
- 규모: 소~중

## 2. 세부 결정 사항 (스타일과 별도)

1. **다양성 표현**
   - ㄱ. 성별 2 + 연령(아이·청년·노인) 구분
   - ㄴ. 성별만
   - ㄷ. 체형·헤어 슬라이더식 조합(개발 확장)
2. **착용 표현**
   - ㄱ. 현행 유지(본 앵커 3D 부착)
   - ㄴ. 의상 전체 교체형(옷이 몸통 메시를 감싸기)
3. **애니메이션 우선순위** (다중 선택)
   - 작업 모션(벌목·채굴·채집) / 수면(눕기) / 대화(제스처) / 운반(짐 들기) / 감정(웃음·슬픔)
4. **이름표·배지 룩** — 현재 텍스트 오버레이 유지 or 스타일에 맞춰 재디자인

## 3. 참고: 스타일별 관전 시너지

- 살아있는 마을을 '지켜보는' 게임 특성상 **실루엣 가독성**(누가 누군지 멀리서 식별)이 1순위 — 스타일보다 색·실루엣 다양화가 체감에 더 큽니다.
- 말풍선·활동 배지·욕구 바는 이미 구현되어 어떤 스타일과도 결합됩니다.
