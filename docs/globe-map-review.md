## 현재 평면 가정의 전수 목록(구형화 영향 지도)

조사 완료(2026-10-23). 상세 파일:라인은 세션 기록 참조.

1. **데이터 계약(../terrafolk)** — `mapJson` = Tiled 정사각 그리드(§1,
   brain `world.py SIZE=128`), `AgentState/ResourceState.x,y` 평면 타일 좌표
   (§3.2·§3.3), 룸 `locomotion.ts` 이동 목적지 클램프(맵 가장자리, 랩 없음).
2. **WorldData(data.rs)** — `terrain/height` 1차원 평면 배열, `idx=y*size+x`,
   `surface_height(x,y)→f32` 연속 표면장, 맵 밖 = 물 센티넬.
3. **지형 메시(terrain.rs)** — `(2n)×(2n)` 평면 쿼드 단일 메시 + 해양 밑판
   수평 쿼드, 정점 `[x, surface_height, z]`. 청크·LOD 없음.
4. **물(water.rs)** — 수면 = 평면 1장(y=−0.18, size×3), 해안거리 BFS도 평면.
5. **이동·착지** — `live_move`(XZ 등속)·`wander`·`ground_snap`(발밑 표면−lift)
   ·소품/자원/건축 착지 전부 `surface_height` 계열(호출처 17곳).
6. **카메라·입력** — 원근 아이소(요 0°·피치 35°), `ground_at` = 광선∩수평면
   y=const(그랩 팬·핀치·줌투커서 전부), 팬 타깃 사각 클램프 [2, size−2],
   `cam_dist(zoom)` 줌=거리 직접 매핑.
7. **DOM(웹)** — 미니맵 선형 등장방형 투영(tf-minimap.js), TF_VIEW 사각
   뷰박스, 이름표는 Rust 투영 좌표 소비(간접 의존).
8. **하늘·시간(daynight.rs·sky.rs)** — 태양 원점 둘레 반경 60 배치(평면천),
   별 상반구 +Y, 새 떼 사각 랩.
9. **안개(terrain_splat.wgsl)** — 고정 뷰 방향·거리 140 상수(수평 지면 근사).

## 안별 상세

### A. 착시 곡률(렌더 변환만)
- **방법**: 카메라 줌아웃 구간에서 월드 좌표를 매 프레임 정점 셰이더에서
  구면으로 휘며 줌·연출 파라미터로 반경을 보간(줌인=현재 평면, 줌아웃=
  작은 행성 실루엣). 지형·소품·주민 전부 같은 변환을 타면 정합 유지.
- **고려**: 물 평면·안개·그림자·미니맵 뷰박스는 평면 공식이라 줌아웃 구간
  연출(수면 밴드·지평선 안개) 별도 처리 필요. DOM 이름표 투영은
  `world_to_viewport`가 3D 카메라를 쓰므로 자동 정합(곡률 변환을 뷰 행렬
  앞 단계에 넣으면).
- **리스크 낮음**: 되돌리기 쉽고, 게임플레이·계약 무결. 룩 지향점(핸드페인트
  코지 아이소)과도 양립 — 기본 시점은 그대로, 줌아웃에서만 행성감.

### B. 클라 전용 구면 — 비권장 이유
- 서버는 평면 클램프 이동을 계속하므로 구면 이음새(경도 랩·극 수렴)에서
  주민이 "맵 끝에서 반대편"으로 이어지지 않음 — 행성인데 마술 벽 존재.
- `surface_height` 계열 17개 호출처 + 카메라 광선 판정 + 미니맵 전부 재작성.
- 2D 레거시 FE(평면)와 3D(구면) 패리티 영구 분기.

### C. 진짜 행성 — 조건부
- 전제: 계약 §1·§3 재정의(위경도 or 청크 좌표), 룸 배위·브레인 월드 생성
  구면화, 두 FE 동시 갱신, 맵 생성기(섬 마스크 방사 대칭 → 구면 노이즈) 재작업.
- 얻는 것: 경계 없는 관전 세계, "작은 행성" 정체성(차별화 요소).
- 북극성 부합도: 높음(살아있는 세계 관전). 다만 현재 최우선 과제(주민
  생명감·외형·발명 체인 완성도) 대비 우선순위는 낮다.
